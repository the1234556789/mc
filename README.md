<p class="small"><strong>问：</strong>多人游戏联机问题</p>
<p>答：Minecraft只支持1.20版本局域网联机和 P2P 远程联机。<br>
局域网联机——将多个设备连接至同一个网络下，其中一个设备开启“共享世界”，其它设备的“多人游戏”里会自动搜索到开启的自定义房间。<br>
P2P 远程联机——当多个设备不在同一个网络时，确保开启“共享世界”的设备有公网 IP 或 FullCone(NAT1)，且所有设备连接至同一个中继服务器，其它设备的“多人游戏-直接连接-加入共享世界”里输入对应的邀请码就能远程联机。<br>
Minecraft不提供任何形式的联机服务（规避风险）。您的联机数据不经过Minecraft的服务器，而是 P2P 直连。若您没有公网 IP 或 FullCone(NAT1) 则无法实现远程联机（随着 IP 地址的枯竭，大部分用户都处于大内网 NAT 环境中，不过您可以尝试联系网络运营商开启公网）。</p>
